ime-Series Store with Anomaly Detection: Build a simple database for storing and querying time-stamped data (like sensor readings), designed to quickly retrieve all readings between two given times. Implement an efficient indexing structure (such as a Skip List or B-Tree) from scratch instead of scanning the full dataset for every query, then layer a basic anomaly-detection method on top that flags unusual spikes or drops using the fast range queries. Evaluation will focus on correct indexing implementation, query speed compared to a simple linear scan, and the accuracy of the anomaly detection.
